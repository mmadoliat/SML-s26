# Problem 5: Ridge Regression as a MAP Estimator (Gaussian Prior + Gaussian Likelihood)

## Setup

Let

-   Prior on coefficients:\
    $\boldsymbol{\beta} \sim \mathcal{N}(\mathbf{0}, \tau^2 \mathbf{I})$
-   Sampling model (likelihood):\
    $\mathbf{y}\mid \boldsymbol{\beta} \sim \mathcal{N}(\mathbf{X}\boldsymbol{\beta}, \sigma^2 \mathbf{I})$

We will show the **ridge regression estimator** is the **MAP (posterior mode)** and then relate the ridge penalty $\lambda$ to $\sigma^2$ and $\tau^2$.

------------------------------------------------------------------------

## Likelihood and Prior (up to proportionality)

### Likelihood

$p(\mathbf{y}\mid \boldsymbol{\beta}) \propto \exp!\left( -\frac{1}{2\sigma^2}\|\mathbf{y}-\mathbf{X}\boldsymbol{\beta}\|_2^2 \right)$

### Prior

$p(\boldsymbol{\beta}) \propto \exp!\left( -\frac{1}{2\tau^2}\|\boldsymbol{\beta}\|_2^2 \right)$

------------------------------------------------------------------------

## Posterior and Log Posterior

By Bayes’ rule (dropping constants not depending on $\boldsymbol{\beta})$:

$p(\boldsymbol{\beta}\mid \mathbf{y}) \propto p(\mathbf{y}\mid \boldsymbol{\beta}).p(\boldsymbol{\beta}) \propto \exp\left( -\frac{1}{2\sigma^2}\|\mathbf{y}-\mathbf{X}\boldsymbol{\beta}\|_2^2 -\frac{1}{2\tau^2}\|\boldsymbol{\beta}\|_2^2 \right)$

Taking logs (again ignoring additive constants):

$\log p(\boldsymbol{\beta}\mid \mathbf{y}) = -\frac{1}{2\sigma^2}\|\mathbf{y}-\mathbf{X}\boldsymbol{\beta}\|_2^2 -\frac{1}{2\tau^2}\|\boldsymbol{\beta}\|_2^2 + C$

Maximizing the posterior is equivalent to minimizing the negative log posterior:

$\boldsymbol{\beta}_{\text{MAP}} = \arg\min_{\boldsymbol{\beta}} \left\{ \frac{1}{2\sigma^2}\|\mathbf{y}-\mathbf{X}\boldsymbol{\beta}\|_2^2 + \frac{1}{2\tau^2}\|\boldsymbol{\beta}\|_2^2 \right\}$

Multiplying the objective by $2\sigma^2$ (which does not change the minimizer):

$\boldsymbol{\beta}_{\text{MAP}} = \arg\min_{\boldsymbol{\beta}} \left\{ \|\mathbf{y}-\mathbf{X}\boldsymbol{\beta}\|_2^2 + \frac{\sigma^2}{\tau^2}\|\boldsymbol{\beta}\|_2^2 \right\}$

This is exactly the ridge regression objective.

------------------------------------------------------------------------

## Closed-Form Solution (MAP = Ridge)

Differentiate the negative log posterior (or the ridge objective) and set to zero.

From $\frac{1}{2\sigma^2}\|\mathbf{y}-\mathbf{X}\boldsymbol{\beta}\|_2^2 + \frac{1}{2\tau^2}\|\boldsymbol{\beta}\|_2^2$

the gradient w.r.t. $\boldsymbol{\beta}$ is $-\frac{1}{\sigma^2}\mathbf{X}^\top(\mathbf{y}-\mathbf{X}\boldsymbol{\beta}) +\frac{1}{\tau^2}\boldsymbol{\beta}$

Set equal to zero: $-\frac{1}{\sigma^2}\mathbf{X}^\top\mathbf{y} +\frac{1}{\sigma^2}\mathbf{X}^\top\mathbf{X}\boldsymbol{\beta} +\frac{1}{\tau^2}\boldsymbol{\beta} =0$

Multiply by $\sigma^2$: $\mathbf{X}^\top\mathbf{X}\boldsymbol{\beta} +\frac{\sigma^2}{\tau^2}\boldsymbol{\beta} = \mathbf{X}^\top\mathbf{y}$

Factor: $\left(\mathbf{X}^\top\mathbf{X}+\frac{\sigma^2}{\tau^2}\mathbf{I}\right)\boldsymbol{\beta} = \mathbf{X}^\top\mathbf{y}$

Thus, $\boxed{\boldsymbol{\beta}_{\text{MAP}} = \left(\mathbf{X}^\top\mathbf{X}+\frac{\sigma^2}{\tau^2}\mathbf{I}\right)^{-1}\mathbf{X}^\top\mathbf{y}}$

------------------------------------------------------------------------

## Relationship Between $\lambda$, $\sigma^2$, and $\tau^2$

The ridge estimator is commonly written as: $\hat{\boldsymbol{\beta}}_{\text{ridge}} = (\mathbf{X}^\top\mathbf{X}+\lambda \mathbf{I})^{-1}\mathbf{X}^\top\mathbf{y}$

Comparing with the MAP solution above gives: $\boxed{\lambda = \frac{\sigma^2}{\tau^2}}$

Equivalently: $\boxed{\tau^2 = \frac{\sigma^2}{\lambda}}$

------------------------------------------------------------------------

## Interpretation

-   Larger noise variance $\sigma^2$ $\Rightarrow$ stronger regularization (larger $\lambda$).
-   Larger prior variance $\tau^2$ (weaker prior shrinkage) $\Rightarrow$ smaller $\lambda$.
-   Ridge is MAP under a zero-mean isotropic Gaussian prior.
